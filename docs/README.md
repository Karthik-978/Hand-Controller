# Hand Controller

Browser-based hand gesture interaction using MediaPipe Hand Landmarker.

## Live Demo

https://karthik-978.github.io/Hand-Controller/

## Features
- Live webcam hand tracking
- Index finger cursor movement
- Thumb-index pinch click
- Interactive browser workspace
- Local browser-side video processing

## Run
Open the GitHub Pages website using Chrome or Edge.
Allow camera access and click Start Camera.

## Technology
- HTML
- CSS
- JavaScript
- MediaPipe Tasks Vision

## Limitations
This browser demo controls only its own interactive workspace.
It does not control the operating system cursor or desktop applications.
Camera access requires HTTPS or localhost and user permission.
