# 🖐️ Hand Controller

A Python-based hand controller that uses a webcam and computer vision to detect hand gestures and provide hands-free interaction with a computer.

## Features

- 🖐️ Real-time hand gesture detection
- 📷 Webcam-based tracking
- 🖥️ Gesture-based computer control
- ⚡ Real-time interaction
- 🐍 Built with Python

## Requirements

- Python 3.x
- Webcam
- Required Python libraries

## Run

```bash
python hand_controller.py
```

## Project Structure

```text
Hand-Controller/
└── hand_controller.py
```

## Purpose

This project demonstrates how computer vision and hand tracking can be used to create a simple hands-free computer interaction system using hand gestures.
